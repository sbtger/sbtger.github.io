Network Security Notes on Denial of Service

Peng Zhang·2020-03-16·中文

Availability and resource exhaustion

An availability problem can appear as delayed responses to legitimate requests. The bottleneck could be a network link, connections or queues, CPU, storage, or memory. Distributed traffic may come from many sources, so a single host rarely tells the full story.

Checking for memory leaks

A leak occurs when allocated memory is no longer needed but cannot be freed. Growing memory consumption alone does not establish unusual traffic. Examine request volume, load changes, and memory reclamation together.

Connection and traffic metrics

Track interface traffic, active and half-open connections, request latency, error rates, and backend queue depth. Compare with a normal baseline for the same time period to see how incoming traffic correlates with backend saturation.

Response and recovery

Check connection timeouts, queue capacity, routing, and edge-device settings against the actual bottleneck. After applying rate limits, upstream filtering, or isolating a high-load feature, monitor successful legitimate requests to confirm recovery.

Microcomputer Interface Notes on Memory

Peng Zhang·2020-03-19·中文

Connecting memory to the CPU

Interface requirements

  • Check CPU bus loading. Add a buffer or line driver when the load exceeds the bus's drive capacity to keep logic levels valid.
  • Match CPU timing to memory access speed.
  • Allocate address ranges and generate chip-select signals.
  • Connect the control signals.

Address decoding

The 74LS138 is a common 3-to-8 decoder. A decoded output selects the target device for an I/O access or enables a memory chip.

Expanding memory

To expand word width, combine chips to supply more bits per address. To increase the number of words, use separate chip banks and select a bank with high address bits. For both kinds of expansion, determine the word width first, then the number of banks.

Generating chip selects

Direct address-line selection
Simple wiring can waste address space and leave overlapping or noncontiguous ranges.
Full decoding
All relevant high address bits take part in decoding. Inputs can be fixed to implement a specific address range.
Partial decoding
Only some high bits participate. An omitted bit can make the same chip appear at multiple addresses.

Flexible memory addressing

AND and OR instructions

AND can clear selected bits while leaving other bits unchanged. OR can set selected bits while leaving other bits unchanged.

ASCII

ASCII assigns numeric codes to characters, which the computer stores in binary.

Uppercase and lowercase

Uppercase A has ASCII code 41h and lowercase a has code 61h. The lowercase code is 20h higher.

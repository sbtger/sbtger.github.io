Quick start

Four common Hexo commands

hexo g       # Generate static files
hexo s       # Start the local preview server
hexo d       # Deploy the site
hexo clean   # Remove db.json and generated files in public/

See generation, the server, and deployment.

Local preview address

http://localhost:4000/

Writing an article

hexo new [layout] <title>

See the writing guide.

Regenerating after changes

hexo clean
hexo g -d

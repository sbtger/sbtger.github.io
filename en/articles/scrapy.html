The Scrapy framework

The original Windows setup used pip to install Scrapy and dependencies including lxml, Twisted, and pypiwin32.

Choosing a compatible wheel

A wheel is an archive that can contain Python files and precompiled native modules, such as Windows .pyd files. It allows installation without a local build environment.

Check the supported installation tags before choosing a wheel, for example cp37-cp37m-win_amd64. The historical examples below used private pip interfaces whose availability depends on the pip version. For current pip, use python -m pip debug --verbose.

Java 字符串与线程

String.length() 返回 UTF-16 代码单元数。yield() 向调度器提示当前线程愿意让出处理器。线程之后何时再次运行取决于调度器。

等待、唤醒与休眠

方法执行时发生什么
wait()持有对象监视器的线程进入等待集，并释放该对象的监视器。返回前需要重新取得监视器。
notify()从该对象的等待集中唤醒一个线程。被唤醒的线程需要等其他线程释放监视器后才能继续。
sleep()当前线程暂停一段时间。休眠期间它仍持有此前取得的监视器。

HTTP 与移动应用

HTTP 301 表示资源永久迁移，响应可用 Location 指出新地址。Android 的广播接收器既能在清单中声明，也能随组件生命周期动态注册。发布包做代码收缩和混淆时，可分别检查包体积与名称映射文件。

Shell 位置参数

Shell 脚本中，$0 是脚本名，$1 是第一个传入参数，$# 是参数个数，$? 是上一条命令的退出状态。使用带双引号的 "$@" 可以保留各个参数的边界。

服务权限与消息有效期

数据库与缓存服务应限定监听范围、调用方身份和账号权限。对于一次性请求，还需要核对消息有效期及唯一标识，避免合法请求被重复受理。
